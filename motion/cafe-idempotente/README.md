# Café idempotente

Composição HTML / GSAP renderizada com HyperFrames 0.8.114. 960 × 540, 20 segundos, timeline desacelerada em 50%, sem áudio.

`npx hyperframes@0.8.114 check`

`npx hyperframes@0.8.114 render --format gif --gif-loop 0 --fps 15 --workers 1 --output ../../site/assets/cafe-idempotente.gif`

Requer FFmpeg e FFprobe no PATH. O GIF é finito; a repetição infinita é configurada no arquivo exportado. O artigo oferece pausa e respeita a preferência de movimento reduzido.
